# 📊 Business Analytics Dashboard (RFM + CLTV + Recommendation)

## 🚀 Live App
👉 https://business-analytics-app.streamlit.app

---

## 📌 Project Overview
This project is an interactive **business analytics dashboard** built with Streamlit.  
It provides customer segmentation, CLTV analysis, and business insights for data-driven decision making.

---

## 🎯 Business Problem
Companies struggle with:
- Identifying high-value customers
- Detecting churn risk
- Measuring customer lifetime value
- Making data-driven marketing decisions

This project solves these using data analytics.

---

## 🧠 Methods Used

### 📊 RFM Analysis
Customers are segmented using:
- Recency
- Frequency
- Monetary value

### 💰 CLTV Analysis
Customer lifetime value is calculated using:
- Average order value
- Purchase frequency
- Total revenue

### 📦 Segmentation Output
- Champions
- Loyal Customers
- Potential Loyalists
- At Risk Customers
